Kaggle Success Factors Analysis 📊

A comprehensive Power BI dashboard project analyzing the key factors behind successful Kaggle content, including notebooks, datasets, engagement trends, author influence, virality, and programming language popularity. This project provides interactive insights into what drives views, upvotes, and community engagement on Kaggle.

🚀 Project Overview

This dashboard explores Kaggle platform trends using interactive Power BI visualizations. The analysis focuses on:

Content performance over time
Author popularity and engagement
Programming language trends
Topic-wise performance analysis
Viral content behavior
Engagement metrics and interaction breakdown

The dashboard helps identify the success factors behind highly viewed and highly engaged Kaggle content.
